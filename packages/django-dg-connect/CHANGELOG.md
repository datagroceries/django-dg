# Changelog of django-dg-connect

## 1.0.0 (2026-11-07)

The first release: OAuth for the Claude connector on django-oauth-toolkit (Client ID Metadata Documents
from Claude's hosts and VS Code's, PKCE, rotated refresh tokens, hashed storage), personal `dg_`
tokens, and the "Connect an agent" page with every connected app and token, in English and Dutch. Tested
with claude.ai, Claude Code and VS Code.
