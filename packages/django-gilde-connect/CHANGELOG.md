# Changelog of django-gilde-connect

## 1.0.0 (unreleased)

The first release: OAuth for the Claude connector on django-oauth-toolkit (Client ID Metadata Documents
from Claude's hosts, PKCE, rotated refresh tokens, hashed storage), personal `gilde_` tokens, and the
"Connect an agent" page with every connected app and token. Tested with claude.ai and Claude Code.
